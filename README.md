# S3R 电源系统因果融合故障诊断

本项目实现面向卫星 S3R 电源系统遥测的故障诊断模型。模型结合电路拓扑约束下的空间图、物理先验约束下的时序预测依赖，以及边级和特征级门控融合，对预定义的单故障模式进行分类。

## 项目结构

| 文件 | 用途 |
| --- | --- |
| `experiment_data.py` | 加载连续遥测区间、计算派生特征、按区间生成窗口并标准化 |
| `temporal_gc.py` | 训练共享 LSTM 预测器，估计每个窗口的有向时序图 |
| `causal_fusion.py` | 空间 GAT、条件变分自编码器（CVAE）和双门控融合模型 |
| `run_experiment.py` | 单个数据集的训练、验证、测试与结果导出入口 |
| `main.py` | 训练入口的兼容包装 |
| `configs/simulated.example.json` | 14 变量模拟数据的配置格式示例 |

## 方法

1. **数据划分与预处理：**通过清单先指定连续记录的训练、验证和测试区间，再在各区间内部以长度 100、步长 50 生成窗口。标准化参数只从训练数据拟合，窗口不会跨越分区或故障注入边界。
2. **空间分支：**根据配置中的 `spatial_edges` 构造固定、对称且含自环的空间先验图。两层图注意力网络仅沿允许的边聚合。辅助分类器的预测概率在训练和推断时都作为 CVAE 的条件；真实标签只用于分类损失。
3. **时序分支：**在原始变量之外计算 9 个派生物理特征，包括 5 个功率特征、2 个电池特征和 2 个调节响应特征。`temporal_edges` 限定候选方向。共享双层 LSTM 使用 20 步历史预测目标变量；将候选源变量的历史替换为独立高斯序列后，以预测误差的非负对数比衡量其贡献，每个源节点最多保留 5 条正权出边。
4. **图融合与分类：**时序图先在原始变量与派生特征组成的图上传播，再按原始变量顺序与空间图对齐。模型计算边级与特征级门控，并在融合图上完成分类。

## 环境与运行

建议使用 Python 3.10、PyTorch 2.3.0，以及与 PyTorch 和本机 CPU/CUDA 环境匹配的 PyTorch Geometric；其他依赖包括 `numpy`、`pandas` 和 `scikit-learn`。参考训练环境为 CUDA 12.1 和 RTX 4060。模型默认使用 Adam（学习率 `0.001`、权重衰减 `0.0001`）、批量大小 64、最多 200 个分类训练轮次。

准备配置文件、遥测 CSV 和清单后运行：

```powershell
python run_experiment.py --config configs/simulated.example.json --manifest data/manifest.csv --output results/simulated
```

真实在轨数据使用独立的 75 列配置、清单和输出目录。可使用 `--epochs`、`--gc-epochs`、`--batch-size`、`--gc-top-k`、`--seed`、`--device` 调整运行。

### 输入数据

遥测 CSV 的列名必须与配置中的 `raw_columns` 匹配，列顺序由配置确定。`roles` 指定计算派生特征所用的 12 个原始变量。输入须为有限数值；如需插值、异常点处理或单位转换，应先在数据准备阶段完成并记录规则。

清单 `manifest.csv` 的每行表示一个连续、单一标签的区间：

```csv
file,split,label,run_id,start,stop
run_01.csv,train,1,run_01,14400,56000
run_01.csv,val,1,run_01,56000,70400
run_01.csv,test,1,run_01,70400,86400
```

`start` 包含、`stop` 不包含；`file` 路径相对清单所在目录。同一 CSV 中的清单区间不得重叠，区间不得跨越故障注入点。每个训练、验证、测试分区都需要覆盖配置的全部诊断类别。若 CSV 包含标称数据，应明确其标签及是否纳入分类任务。

在配置文件中按电路拓扑、控制逻辑和变量定义设置 `spatial_edges`、`temporal_edges` 与 `roles`。真实在轨数据使用对应的 75 字段映射。

### 输出与评估

运行后，输出目录包含：

| 文件 | 内容 |
| --- | --- |
| `best_model.pt`、`temporal_predictor.pt` | 本次训练得到的模型权重 |
| `experiment.json` | 配置、配置与清单的 SHA-256、软件版本、随机种子、窗口数量和测试指标 |
| `scalers_and_priors.npz` | 训练集拟合的标准化参数与图先验 |
| `windows_train.csv`、`windows_val.csv`、`windows_test.csv` | 窗口来源、运行 ID、起止位置和标签 |
| `gc_mean_scores_*.npy` | 各分区的平均时序预测贡献矩阵 |
| `history.csv`、`test_predictions.csv` | 训练过程与测试集预测 |
| `per_class_metrics.csv`、`confusion.csv` | 逐类指标与混淆矩阵 |

模型按验证集 Macro-F1 选择，测试集只在模型选定后评估。指标包括准确率（ACC）、宏平均精确率（PRE）、宏平均召回率（REC）和宏平均 F1。Macro-F1 是各类别 F1 的算术平均；逐类 CSV 在写出时保留四位小数。
